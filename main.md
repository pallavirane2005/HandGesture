# 🤖 Gesture Control System v2.0

A full-stack real-time hand gesture recognition application with a cyberpunk-themed UI.

## Architecture

Backend: FastAPI + WebSocket + OpenCV + MediaPipe
Frontend: React + Tailwind CSS + Lucide Icons
Protocol: WebSocket (JSON + Base64 JPEG stream)

## Quick Start

### Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
