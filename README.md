Gesture Control System using Computer Vision

##📌 Project Overview

This project is a real-time **Hand Gesture Recognition System** developed using **Python**, **NumPy**, **Pandas**, and Computer Vision techniques. The system detects and tracks hand landmarks through a webcam feed and recognizes different hand gestures in real time.

The project utilizes a Kaggle dataset for gesture analysis and classification, enabling accurate recognition of hand movements and finger positions. It demonstrates how computer vision and machine learning can be used to build touchless human-computer interaction systems.

## 🎯 Objective

The primary objective of this project is to create an intelligent gesture recognition system capable of:

- Detecting hand landmarks in real time
- Tracking finger positions
- Identifying different hand gestures
- Displaying gesture confidence scores
- Providing an interactive dashboard for monitoring gesture detection

## 📋 Project Workflow

- Prepare training samples

### Step 2: Data Preprocessing
- Clean dataset
- Extract landmark coordinates
- Normalize feature values
- Convert data into machine learning format

### Step 3: Feature Extraction
- Capture hand landmarks
- Calculate finger positions
- Generate gesture feature vectors

### Step 4: Gesture Recognition
- Analyze finger states
- Compare landmark patterns
- Predict gesture class

### Step 5: Visualization
- Display landmarks
- Show gesture labels
- Present confidence scores
- Update dashboard in real time
